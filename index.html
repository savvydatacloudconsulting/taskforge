Try it yourself (terminal, in this folder)

taskforge controls                         # self-test: good task accepted, bad tasks rejected (about 1 min)
taskforge demo --example library           # full pipeline, offline, replaying recorded answers
taskforge check samples/tasks/shop/shop__time_window__01 --repo examples/shop
taskforge analyze examples/shop            # what TaskForge understands about a repository

This page only shows files. The tool itself runs from the command line, and a demo writes a fresh report to taskforge_out/.
